# Changelog

A living log of doctrine and architecture changes — not a feature changelog for end users, a changelog for the agent (and you) to understand what changed and why.

Add an entry whenever an ADR is superseded, a stop-condition is added/removed, or a do-not-touch boundary changes. Keep entries short — link to the relevant ADR for the full reasoning.

## Format

```
## YYYY-MM-DD

- Superseded ADR-00X ("old decision") with ADR-00Y ("new decision"). See ADR-00Y for why.
- Added stop-condition: [new condition] — reason: [what happened that prompted this]
- Removed do-not-touch entry for [file/system] — reason: [why it's now safe to touch]
```
